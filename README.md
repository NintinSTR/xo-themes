# XO Themes + Deek

A Chrome extension that puts live animated wallpapers behind the [XO Market](https://beta.xo.market) dashboard, with Deek, the XO mascot, roaming the page.

## Features
- 15 animated themes (Koi Pond, Blue Koi Pond, Pink Matrix, Synthwave, Snowfall, City Night, Aurora, XO Halloween and more)
- Custom image, GIF or video wallpaper, plus a theme maker
- Auto day/night, per-page themes, focus mode (Alt+F)
- Deek reacts to your streak and rides the 60s TWAP line on a broom after a Pulse bet
- Hotkeys: Alt+T opens the panel, Alt+1 to Alt+9 pick themes

## Install
1. Download this repo (Code > Download ZIP) and extract it
2. Open `chrome://extensions` and turn on Developer mode
3. Click **Load unpacked** and pick the extracted folder
4. Open beta.xo.market and press Alt+T

## Privacy and safety
- Permissions: `storage` only, runs only on xo.market
- No network requests, no tracking
- Never touches wallet, deposit, withdraw or sign screens, and never clicks anything for you
